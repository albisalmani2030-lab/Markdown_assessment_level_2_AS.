## How Our Ordering Apps Work
every order is added up by our app. we use the `total` variable to keep track of the price:
``` let total = 0
    total = total + 8;

    if (total > 10) {
        consle.log("You get a free cookie);
    } else {
        consle.log("add 💲2 for a free cookie!")
    }    
```
